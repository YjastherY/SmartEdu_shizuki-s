# SmartEdu Presentation Outline

## Slide 1: Title

SmartEdu: educational platform MVP.

## Slide 2: Problem

Students need one place to study courses, watch lessons, pass tests, track progress, receive feedback, and communicate with teachers.

## Slide 3: Solution

SmartEdu combines course catalog, lessons, tests, progress analytics, comments, notifications, chat, teacher review tools, and admin group management.

## Slide 4: Technology Stack

- Frontend: React, Vite, TailwindCSS, React Router
- Backend: Node.js, Express, Prisma
- Database: PostgreSQL
- Auth: JWT
- Deploy: Docker Compose

## Slide 5: Student Flow

1. Register or log in.
2. Open dashboard.
3. Choose a course.
4. Watch video lessons.
5. Complete tests and manual-answer tasks.
6. Track progress and certificates.

## Slide 6: Teacher Flow

1. Create tests with weighted questions.
2. Upload lesson videos.
3. Review manual answers.
4. Leave feedback.
5. Track group and student progress.
6. Extend deadlines for individual students.

## Slide 7: Admin Flow

1. Manage user roles.
2. Assign students to groups.
3. Assign teachers to groups.
4. Attach courses to groups.

## Slide 8: Advanced Features

- WebSocket notifications
- Live student chat
- Learning assistant
- Dark theme
- Responsive interface
- Certificate verification page

## Slide 9: Quality and Deployment

- Docker local/server deployment
- Structured backend logs with request ids
- CI syntax/build checks
- Automated smoke test
- Manual QA checklist
